# Специалист на час

Сайт-портфолио для удалённых заказов и работы по договорённости в Санкт-Петербурге.

Для локального запуска выполните `npm ci`, затем `npm run dev`.
Команда `npm run build` создаёт готовую сборку в папке `dist`.

Контакты в `src/components/ContactForm.tsx` пока представлены заглушками.
Реальные работы, ссылки на проекты и резюме добавляются после сверки.
